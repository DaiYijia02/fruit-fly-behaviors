Static gallery (GitHub Pages) of 20 positive and 20 negative events sampled (seed 0) from the
`easy-same-sex` start-to-chase EventSet `es-efed4657076c` (v4, episode onsets). Each GIF shows

Generated by `concepts/start_to_chase/analysis/animate_eventset_examples.py` in AnimalPoseForecasting.
